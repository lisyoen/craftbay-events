Visual C++(VS2003, VS2005, VS2008)의 문자열 처리 요약

비쥬얼 C의 문자 사용은 의외로 매우 까다롭다. 특히 예전 부터 사용해 오던 코드를 새버젼에 이식하려면 거의 경우에 어느 정도의 수정이 필요하다. 이것은 유니코드 때문이다. 유니코드는 전세계의 모든 문자를 하나의 코드로 나타내기 위해 만들어진 것으로 비쥬얼 C에서 기본적으로 유니코드를 사용하도록 설정되어 있다. 물론 컴파일 지시자에서 UNICODE를 안 쓰도록 지시하면 이전의 상태 그대로 이용할 수 있으나, 그런 경우에도 멀티바이트 문자와 유니코드 문자를 이해하지 못하면 문자열을 사용하는데 매우 혼란 스럽다. 특히, 마이크로소프트사에서 멀티바이트 문자와 유니코드 문자를 가리지 않고 프로그램을 작성할수 있도록하기 위하여 공용코드를 만들었는데, 이것이 혼란을 가중시키고 있다.

 

1. 문자의 종류

     가. 멀티바이트: 8비트 문자, 아스키코드 사용, 한글은 2자리차지함, 끝을 알리기 위해서 '0x00'을 맨 뒤에 넣음

     나. 유니코드: 16비트 문자, 두바이트를 묶어 문자 표현, 8비트 문자와 호환성 없음, 한글은 1자리.

     다. 8,16비트 범용: 컴파일 지시자에서 #define UNICODE 가 있으면 유니코드로 그렇지 않은 경우는 멀티바이트 인식되도록

          두 문자 코드를 구분하지 않고 프로그램을 작성하도록 만들어둔 것들이다.

 

2. 문자열 상수(문자열의 내용이 바뀌지 못하는 것)

     가. 멀티바이트:           char * ch = "메롱";

     나. 유니코드:              wchar_t * ch = L"메롱";

     다. 범용문자:              tchar * ch = _T("메롱");     또는       tchar * ch = TEXT("메롱");   

 

3. 문자의 타입 (문자열이 아닌 하나의 문자를 나타냄, 배열을 이용하여 문자열 나타낸다)

     가. 멀티바이트:           CHAR ch = 'A';              또는       CHAR ch[6] = "메롱";

     나. 유니코드:              WCHAR ch = L'A';          또는      WCHAR ch[6] = L"메롱";

     다. 범용문자:              TCHAR ch = _T('A');      또는      TCHAR ch[6] = _T("메롱");

 

4. 문자열의 타입 (문자열은 원거리 포인터로 나타낸다)

     가. 멀티바이트:          LPSTR lp = "메롱";

     나. 유티코드:             LPWSTR lp = L"메롱";

     다. 범용:                   LPTSTR  lp = _T("메롱");

 

5. 상수인 문자열 타입 (포인터가 가르치는 위치가 바뀌지 못하는 것)

     가. 멀티바이트:          LPCSTR lp = "메롱";

     나. 유티코드:             LPCWSTR lp = L"메롱";

     다. 범용:                   LPCTSTR  lp = _T("메롱");

 

6. 문자의 종류별 문자열 처리용 함수(예)

 기능멀티바이트  유니코드 범용
 문자열 길이 strlen wcslen_tcslen 
 한 문자열 내의 다른 문자열 찾기 strcspn wcscspn_tcscspn 
 문자열 복사 strcpy wcscpy_tcscpy 

*자세한 내용은 MSDN 도움말의 개발도구및언어>>Visual Studio설명서>>Visual C++>>Reference>>Libraries Reference>>Run-Time Library>>Run-Time Routines by category>>String Manupulation 을 참조

 

7. 종류별 상호변환 함수

     가. 멀티바이트 -> 유니코드:    mbstowcs (현재 시스템의 코드페이지를 이용), MultiByteToWideCahr(특정 코드페이지를 지정)

           ex)   CHAR * ch = "메롱";

                  WCHAR wch[6];

                  mbstowcs(wch, ch, strlen(ch));

     나. 유니코드 -> 멀티바이트:   wcstombs (현재 시스템의 코드페이지를 이용), WideCharToMultiByte(특정 코드페이지 지정)

           ex)  WCHAR * wch = "메롱";

                 CHAR ch[6] ;

                 wcstombs(ch, wch, wcslen(wch));

 

8. 문자열을 숫자로 변환

 기능 멀티바이트 유니코드 범용
 문자열을  INT 로 변환 atoi _wtoi _ttoi
 문자열을  LONG으로 변환 atol _wtol _ttol
 문자열을  LONGLONG으로 변환 atoi64 _wtoi64 _ttoi64

 문자열을  DOUBLE로 변환 및

 나머지 문자열 반환

 strtod wcstod _tcstod
 문자열을  LONG으로 변환 및

 나머지 문자열 반환

 strtol wcstol _tcstol
 문자열을  ULONG으로 변환 및

 나머지 문자열 반환

 strtoul wcstoul _tcstoul

 

9. 정수 숫자를 문자열로 변환

 기능 멀티바이트유니코드 범용
 INT를 문자열로 변환 _itoa _itow _itot
 LONG을 문자열로 변환 _ltoa _ltow _ltot
 ULONG을 문자열로 변환 _ultoa _ultow _ultot

 

10. 포맷기능을 이용한 문자열 변환

     가. 멀티바이트: sprintf (포맷기능을 이용하여 멀티바이트 문자열 생성)

     나. 유니코드:    swprintf  (포맷기능을 이용하여 유니코드 문자열 생성)

     다. 범용: wsprintf (포맷의 Field character를 이용하여 문자 비트수 선택 가능함)

              멀티바이트:  %c, %s

              유니코드:     %C, %S

 

11. MFC 문자열 처리 클레스

      가. 멀티바이트: CStringA

      나. 유니코드:    CStringW

      다. 범용      :    CString    혹은   CStringT

 

12. ATL 문자열 처리 클레스

      가. 멀티바이트: CAtlStringA

      나. 유니코드:    CAtlStringW

      다. 범용      :    CAtlString    혹은   CStringT

 

13. MFC의 문자열 집합 클레스

     가. 문자열 배열 : CStringArray

     나. 문자열 링크드 리스트 (linked list) : CStringList

     다. 문자열 Map : CMapStringToPtr, CMapStringToOb, CMapStringToString
