class TestClass
{
public:
  int TestFunc( int arg ) { return ( arg * 2 ); }
};

{
  TestClass* pt = NULL;
  int ret = pt->TestFunc( 4 );
  return ret;
}

단, 최적화 옵션이 낮게 설정되어 있어서 TestFunc 는 inline 처리가 되지 않았다.
