가변 인수(파라미터)

보통 함수를 만들때 함수이름(파라미터1, 파라미터2) 이런식으로 만들게 됩니다만 함수의 파라미터를 딱히 정의 할수 없는 경우도 종좋 발생 하게 됩니다.

이럴경우에 가변 인수 함수를 사용하면 되는데 우리가 C언어를 처음 배울때 쓰는 printf()가 좋은 예입니다. printf함수를 쓸때
1.printf("정수: %d", i);
2.printf("정수: %d 실수:%f", i, f);
3.printf("실수:%d 문자열:%s",f,s);

이런 식으로 쓰게 되는데 처음에 전달되는 문자열만 빼고 나머지 파라미터들은 가변적이게 됩니다. 그럼 printf의 정의 부분으로 가보면
1.printf(_In_z_ _Printf_format_string_ const char * _Format, ...);


이런식으로 정의 되어 있는 걸 볼수 있는데 바로 위에서 언급한 것 처럼 _Format은 고정, ... 로 표기된 부분은 가변적이게 되는 것입니다.

가변 인수 함수를 만드는 방법은 위의 printf와 다르지 않습니다. 여기서는 write함수를 만들어 보면서 설명해 가겠습니다.

먼저 선언 방법을 보면

가변 인수 함수의 선언
1. 함수에 사용된 고정 파라미터들을 세팅한다(printf의 _Format)
2. 가변 인자들은 '...'로 표기한다.

실제 write함수를 선언해 보겠습니다.
1.Write(const char* _msg, ...);


구현 방법도 어렵지 않습니다. 우선 write함수의 구현 부분을 보겠습니다. 
1.void Write(const char* _msg, ...)
2.{
3.       va_list ap;
4.       va_start(ap, _msg);
5.       printf_s(_msg, ap);
6.       va_end(ap);
7.       fprintf_s(m_pFile, "\n");
8.}

여기서 중요한 부분이 바로 va_list형과 va_start함수, va_end함수 입니다.
va_list:
뒤에 들어가는 가변 인수들의 주소를 기억하는 변수 이고 typedef char *  va_list로 정의 되어 있습니다.
va_start(va_list, 마지막 고정파라미터):
가변인수 첫번째를 가리키게 됩니다. 마지막 고정파라미터를 넣어 줌으로서 주소를 가리킬수 있게 됩니다.
구현부를 보시면 확실히 이해가 됩니다.
 
1.#define va_start(ap,v) ( ap = (va_list)_ADDRESSOF(v) + _INTSIZEOF(v) )
va_end(va_list):
가변 인수들을 모두 읽은 후 마무리 작업을 하는 함수 입니다. 별다른 기능은 없지만 플랫폼간 호환성을 위해 va_start() 함께 쓰는게 좋습니다.
 
1.#define va_end(ap) ( ap = (va_list)0 )


마지막으로 write함수의 활용 소스를 보겠습니다.
1.void Export(char* _Msg, int _Number)>
2.{
3.     Write("%d::%s \n",_Number, +Msg);
4.}

이럴 경우 Write함수는 printf함수와 똑같은 기능을 하게 됩니다.
