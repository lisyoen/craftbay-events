Why not?

C/C++ 표준 에서는 타입명(Class, Structure, Enumeration 등)과 동일한 이름의 변수명을 사용할 수 없도록 제한하고 있다.
즉,


class Test

{

........

};

Test Test = new Test(); // Error!!

이런 구문은 에러가 발생한다는 뜻이다.

너무나도 당연시 되던 이 제한.

왜 있는걸까?

참고로 C# 에는 이 제한이 없다.

필자가 찾아낸 한 가지 이유는 sizeof 키워드. 또 다른 이유가 있을까?
