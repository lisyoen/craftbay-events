2bits parity check. for 32 bits data

오늘 문뜩 32bits 데이터의 2bits 짝수 패리티 체크 함수를 만들다가.

번쩍!

// 2bits even parity check
bool CheckParity(unsigned long uData)
{
    uData ^= (uData >> 16);
    uData ^= (uData >> 8);
    uData ^= (uData >> 4);
    uData ^= (uData >> 2);
    return ((uData & 0x3) == 0);
}

근데 결국 사용하지 않게 되었다.
에러 체크 방법이 패리티가 아니더라고... 췟.
