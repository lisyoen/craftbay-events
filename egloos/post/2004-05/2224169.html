재미있는 주석 처리

C++ 에는 /* */ 스타일과 // 스타일의 두가지 주석을 지원한다.


이 두가지를 혼용하면 편리한 주석 스위치가 가능하다.


다음 소스를 보자.



//*/
int a = 10;
/*/

int a = 20;

//*/

여기서 맨 앞에 있는 / 를 삭제하면 다음과 같이 된다.



/*/

int a = 10;
/*/
int a = 20;
//*/

주석 블럭이 스위치 되었다.


/*/ 을 더 많이 넣을 수도 있다. 그렇게 되면 홀수, 짝수 블럭이 동시에 교체된다.


개인적으로 매우 쓸모있는 팁이라고 생각한다.
