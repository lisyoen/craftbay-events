이제는 널 지우려고 해

null 을 delete 해버리면 어떻게 될까?

if (pData) delete pData;

이 얼마나 숱하게 써온 구문이던가.
그런데 null 을 delete 하면 에러가 발생한다고 적혀 있는 책을 본 적이 있는가?
아니면 그렇게 가르치는 선생님, 교수님을 본 적이 있는가?

C++ 표준에 의하면 delete 는 null 을 처리할 수 있도록 (하지만 아무것도 '처리' 하지 않도록) 정의되어 있다.
하지만 나는 항상 null 이 들어가지 않도록 하기 위해 수 없이 if 구문을 쳐대거나
SAFE_DELETE 따위의 매크로를 만들어서 써댔다.

정말. 모르면 손발이 고생한다는 말이 정확히 들어맞는 상황인것 같다.
