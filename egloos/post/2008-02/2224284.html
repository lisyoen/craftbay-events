Prime number

소수(Prime number)는 자기 자신과 1 이외의 자연수로 나누어 떨어지지 않는 자연수를 말한다.
예를 들자면 2, 3, 5, 7, 11, 13.. 등이 있다.

[문제] 자연수 N이 소수인지 아닌지를 판별하는 알고리즘을 시간복잡도 O( sqr(N) ) 이하로 기술하시오.

흔히들 학교에서 배우는 O(N) 알고리즘은 이렇게 기술할 수 있겠습니다.
'N을 2부터 N-1 까지의 자연수로 나누어 나머지가 0이 되는 값이 존재하면 소수가 아니다'
수도코드(Pseudocode)로 나타내면 다음과 같습니다.

c 를 2 부터 N-1 까지 1 씩 증가시키며 순환
{
    N/c 의 나머지가 0 이면 N 은 소수가 아님. 끝.
}
N 은 소수임. 끝.

뜬금없는 문제 죄송합니다.
어떤 형식이라도 좋으니 기술해보세요.

혹시 O( sqr(N) ) 미만의 시간 복잡도로 풀 수 있을까요?
