const 와 pointer

void encode(const int* src)
{

src++; // OK

(*src)++; // Error

}

결국 const 인 것은 src 가 아니라 *src 인 셈이다.

이로 미루어 볼 때 int* src 의 의미는.

int* src; // src 변수는 int 형의 포인터 이다.

가 아니라

int *src; // src 라는 포인터는 int 형이다.

라고 볼 수 있다.

이것은

int * a, b;

에서 a 만 포인터인 것과 일맥상통한다.
