구간 주석(/* */) 주의사항

* 이 게시물은 이글루로 옮겨오면서 손상되었습니다. 주석 표시가 되지 않는군요.

* 흔히 알고 있는 내용이지만 정리도 할겸 참고삼아 적습니다.
구간 주석(/- 으로 시작해서 *- 으로 끝나는)은 오류 발생 가능성이 있어서 사용에 주의가 필요하다.
구간 주석은 중첩 사용할 경우 오류를 발생시킨다.

원본 소스다.
01 int a = 10;
02 /- 원래의 주석 블록
03 int b = 20;
04 *-
05 int c = 30;

주석을 중첩시키면 아래와 같이 된다.
01 /- 추가된 주석 블록
02 int a = 10;
03 /-
04 int b = 20;
05 *-
06 int c = 30;
07 *-
원래 의도와는 다르게 06번 라인은 주석에서 제외되었으며 07번 라인에서는 문법에러가 발생한다.
그래도 문법에러가 발생하는건 다행이다.
필자의 주석 방식대로라면 문법에러도 발생하지 않는다.
01 /- 추가된 주석 블록
02 int a = 10;
03 /-
04 int b = 20;
05 //-/
06 int c = 30;
07 //-/ 이게 필자의 주석 닫는 방식이다
보기 좋게 예외 상황이 발생했다.
이런 경우를 막기 위해서 구간 주석 보다는 전처리 구문인 #if 나 #ifdef 를 사용한다.
01 #if 0 // 추가된 주석 블록
02 int a = 10;
03 #if 0 // 원래의 주석 블록
04 int b = 20;
05 #endif
06 int c = 30;
07 #endif
단, 이 경우에 VC++ 편집기는 전처리 구문을 주석으로 표시하지 않는다. (녹색으로 표시하지 않는다)
일부 편집기들은 전처리 구문으로 제외시킨 코드를 별도의 색으로 표시해주기도 한다.
각각 장단점이 있으므로 필요에 맞춰 사용하는 것이 중요하겠다.

* 사실 주석도 전처리 구문이다. 즉, 전처리기(Preprocessor)를 통과하면 소스에서 사라진다. 보통 #이 붙은 것만을 전처리 구문으로 부르고 있기 때문에 여기서는 별도로 구분했다.
