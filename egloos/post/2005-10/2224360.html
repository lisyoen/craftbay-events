보안의 목적

어떤 네트워크 시스템을 구축하려고 한다.
거기엔 온라인 결재를 이용한 사이버머니가 존재하고
사이버머니를 이용한 사용자들간의 거래가 존재한다.
이곳에 필요한 보안사항과 구현방법은 무엇일까?

생각의 순서.

1. Why?
: 어째서 보호해야 하는가?
- 신뢰성 있는 결재 및 거래를 보장해 금전의 유실을 막기 위해.

2. What?
: 무엇을 보호해야 하는가?
- 결재정보
- 결재의 무결성
- 거래정보
- 거래의 무결성

3. From who? Who is the eneny?
: 누구로 부터 보호해야 하는가? 적이 누구인가?
- 사용자의 결재 정보를 가로채려는 해커
- 결재를 위장/조작하려는 해커 또는 악성 사용자
- 사용자의 거래 정보를 가로채려는 해커
- 거래를 위장/조작하려는 해커 또는 악성 사용자

4. What is weakness?
: 무엇이 취약점인가?
- 해커가 시스템과 사용자간의 연결에 접근할 수 있음.
- 해커가 시스템과 연계 시스템(결재 시스템 등)의 연결에 접근할 수 있음.
- 해커가 서버 시스템에 접근할 수 있음.
- 해커가 사용자의 클라이언트 시스템에 접근할 수 있음.
- 해커와 정상 사용자를 구분할 수 없음.

5. From what? What is the enemy's weapon(Information)?
: 어떤 것으로부터 보호해야 하는가? 적의 무기(정보)가 무엇인가?
- 해커가 시스템과 사용자간의 연결에 접근하여 Intercept, Replay, Relay 공격
- 해커가 사용자의 컴퓨터에 접근하여 Key logging
- 해커가 클라이언트 시스템의 구조를 추측/분석하여 Encryption/Dectyption Logic 을 알아낼 수 있음.
- 악성 사용자가 자신의 개인 정보를 허위로 입력할 수 있음.
- 해커가 시스템과 사용자간의 연결을 임의로 중단시킬 수 있음.
- 악성 사용자가 시스템과 자신과의 연결을 임의로 중단시킬 수 있음.
- 해커가 시스템 관리자에게 거짓말을 할 수 있음.(Social engineering)
- 악성 사용자가 시스템 관리자에게 거짓말을 할 수 있음.(Social engineering)
- 해커가 사용자에게 거짓말을 할 수 있음.(Social engineering)

6. How to defense?
: 어떻게 막을까?

여기까지는 보안 중심적인 생각.
공격자의 입장에서 다시 생각해보면.

1. Why? What do I want?
: 왜 공격하는가? 무엇을 원하는가?

2. What is target?
: 무엇을 공격해야 하는가?

3. What is my waepon?
: 내가 가진 무기는 무엇인가?

4. How?
: 어떤 방법으로 공격해야 하는가?

생각 나면 더 적자.
