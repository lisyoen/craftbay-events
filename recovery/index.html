우선 CraftBay MCP 복구

MCP가 응답하지 않을 때 - Recovery MCP로 복구

Recovery MCP의 exec_command로 실행:

1
PM2 상태 확인 
ssh spark "pm2 list"
2
MCP 서버 재시작 
ssh spark "pm2 restart mcp-server"
3
MCP 로그 확인 
ssh spark "pm2 logs mcp-server --lines 20"
복구 후 사용자에게 CraftBay MCP 재연결 요청 (claude.ai 새로고침 또는 MCP 재연결)
