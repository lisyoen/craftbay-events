RTunnel Browser Script

1 Scripty 확장 설치

먼저 브라우저에 Scripty 확장을 설치합니다:

  • Chrome Web Store - Scripty
  • Edge Add-ons - Scripty

Scripty는 웹페이지에 JavaScript를 주입하는 무료 확장 프로그램입니다.

2 스크립트 URL 복사

아래 URL을 복사합니다:

https://events.craftbay.io/rtunnel/browser.js

3 Scripty에 스크립트 추가

  • 브라우저 툴바에서 Scripty 아이콘 클릭
  • "Add New Script" 또는 "+" 버튼 클릭
  • Name: RTunnel
  • URL Pattern: *://*/* (모든 사이트) 또는 특정 도메인 지정
  • Script URL: 위에서 복사한 URL 붙여넣기
  • 저장

4 hostname 설정

스크립트가 처음 실행되면 hostname 입력 프롬프트가 나타납니다.

예시: DESKTOP-OFFICE, LAPTOP-HOME

Tip: URL 파라미터로 미리 설정할 수도 있습니다:
https://example.com?rtunnel_hostname=MY-COMPUTER

5 연결 확인

브라우저 개발자 도구(F12) 콘솔에서 확인:

// 연결 상태 확인 window.rtunnel.getStatus() // 수동 재연결 window.rtunnel.reconnect() // hostname 변경 window.rtunnel.setHostname('NEW-NAME')

지원 기능 Scripty Mode

  • click - 요소 클릭
  • type - 텍스트 입력
  • getText / getHTML - 요소 내용 가져오기
  • selectAll / insertText - 에디터 제어
  • navigate - 페이지 이동
  • openTab - 새 창 열기
  • eval - JavaScript 실행
참고: Scripty 모드에서는 Chrome Extension API를 사용할 수 없어 listTabs, closeTab, activateTab 등 탭 제어 기능이 제한됩니다.
