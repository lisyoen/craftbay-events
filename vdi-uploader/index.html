⬆️ 사용 방법

# 1. 클라이언트 파일 다운로드
Upload.bat + Upload-ToCraftBay.ps1 같은 폴더에 저장

# 2. Upload.bat 더블클릭으로 실행

# 3. 파일 선택 창에서 업로드할 파일 선택
Ctrl+클릭으로 여러 파일 선택 가능

# 4. 업로드 완료 후 URL 확인
파일 탭에서 다운로드 가능
