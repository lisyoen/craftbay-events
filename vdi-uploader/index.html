🚀 사용법

# 1. 먼저 연결 테스트
powershell -ExecutionPolicy Bypass -File .\Test-WebSocket.ps1

# 2. 파일 업로드 (GUI)
powershell -ExecutionPolicy Bypass -File .\Upload-ToCraftBay.ps1

# 3. 특정 파일 직접 업로드
powershell -ExecutionPolicy Bypass -File .\Upload-ToCraftBay.ps1 -FilePath "C:\data\file.zip"
⚠️ 실행 정책 오류 시
반드시 -ExecutionPolicy Bypass 옵션과 함께 실행하세요.
