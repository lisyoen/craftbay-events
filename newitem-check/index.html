📦 신상업뎃확인 앱 기획서

문서 버전: v0.2 (2025-12-28) | 원본: v0.1 (2025-05-24) | 상태: 초안 - 검토 필요

1. 개요

1.1 서비스 목적

타오바오/알리바바 판매처들의 신상품 업데이트 여부를 자동으로 확인하고, 날짜 및 상태를 알림으로 표시하는 Windows 데스크탑 앱

1.2 핵심 가치

  • 300개 이상의 판매처를 한 번에 자동 체크
  • 신상품 업데이트 시 즉시 알림
  • 바탕화면에 항상 띄워놓고 사용 (메모장처럼)

1.3 대상 사용자

  • 중국 도매 상품을 취급하는 국내 셀러
  • 타오바오/알리바바에서 소싱하는 사업자

2. 주요 기능

2.1 기능 목록

No기능설명
①신상확인등록된 모든 판매처 URL을 순차 호출하여 신상품 여부 체크
②삭제 버튼해당 판매처 행 삭제 (URL, 정보 모두 제거)
③판매처명클릭 시 수정 팝업, 우클릭 시 상단고정
④최신신상날짜자동 갱신, 날짜순 정렬, 클릭 시 해당 페이지 오픈
⑤확인체크박스선택 시 필드 색상 변경 (확인 완료 표시)
⑥스크롤바300개+ 판매처 지원 (가상 리스트 또는 페이지네이션)
⑦추가 버튼신규 판매처 등록 팝업 호출
⑧저장 버튼등록 정보 저장 (자동 저장 검토 필요)
⑨팝업 & 엑셀추가단일 등록 + 엑셀 일괄 등록 (중복 제외)
⑩자동신상체크스케줄링 기반 백그라운드 체크 + Push/카톡 알림

2.2 상태별 색상 표시

상태색상설명
신상 업데이트 감지레몬색마지막 확인보다 최신 날짜 감지
체크 실패레드신상은 있는데 파싱 실패
확인 완료화이트사용자가 체크박스 선택

5. 기술 요구사항

5.1 플랫폼

  • Windows 데스크탑 앱
  • 항상 위 (Always on Top) 옵션 지원
  • 시스템 트레이 최소화

5.2 외부 연동

  • 네이버 웨일: 신상 페이지 열기 (기본 브라우저 대체 가능)
  • Push 알림: Windows 알림 센터
  • 카카오톡 알림: 카카오 비즈메시지 API (선택)

5.3 성능 요구사항

  • 300개+ 판매처 목록 부드러운 스크롤
  • 순차 체크 시 진행률 표시
  • 백그라운드 체크 시 CPU/메모리 최소화

A. 핵심 로직 - 신상품 감지 방법

A.1 파싱 방식

  • 타오바오/알리바바 페이지의 어떤 요소에서 신상품 정보를 추출하는가?

A.2 인증 요구사항

A.3 크롤링 제한 대응
